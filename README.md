# رسائل حوارية لغير المسلمين

موقع ثابت (HTML + CSS + JavaScript) بلا مكتبات خارجية، عدا مكتبة Supabase للحسابات التي تُحمَّل عند الحاجة فقط.

## البنية

```
index.html          بنية الصفحة فقط
admin.html          صفحة الإحصاءات والمشتركين (للمشرفين)
privacy.html        سياسة الخصوصية (رابطها في نافذة الاشتراك وفي شاشة موافقة Google)
css/fonts.css       تعريفات الخطوط المحلية
css/main.css        التنسيقات والتجاوب والوضع الداكن
css/admin.css       تنسيقات صفحة الإحصاءات
js/app.js           منطق الصفحة (التنقل، القوائم، المشاركة، التفضيلات، نافذة الحساب)
js/data.js          الرسائل والأديان واللغات والتوجيهات والدول — عدّل هنا لتغيير المحتوى
js/auth.js          الحسابات عبر Supabase (الدخول، الاشتراك، استعادة كلمة المرور)
js/track.js         تسجيل الاستخدام للإحصاءات
js/admin.js         منطق صفحة الإحصاءات
js/config.js        رابط مشروع Supabase ومفتاحه العام
js/card.js          توليد صورة البطاقة للتحميل والمشاركة
js/qr.js            مولّد رموز QR
supabase/schema.sql جداول قاعدة البيانات وصلاحياتها ودوال الإحصاءات
fonts/              ملفات الخطوط (woff2)
images/             الشعار، QR الموقع، يد السحب
server.js           خادم Node بسيط للنشر على Railway
```

## تعديل المحتوى

- لإضافة رسالة أو تعديلها: `js/data.js` ← `MESSAGES`.
- لإضافة دين جديد: أضِف مجموعة في `MESSAGES` وسطرًا في `RELIGIONS` يشير إليها بمفتاح `key` جديد.
  لا تغيّر `key` لدين موجود، فالإحصاءات محفوظة به.
- الآيات داخل `<span class="q">` والمرجع داخل `<span class="ref">`.

## المفضلة

زر ♡ أسفل كل رسالة يحفظها في المفضلة، للزائر والمشترك. الزائر تُحفظ مفضلته في متصفحه (`om-favs`)،
والمشترك في حسابه (جدول `favorites`) فيجدها على أي جهاز.
عرض المفضلة (زر «المفضلة» في الشريط والقوائم) للمشتركين: الزائر تُفتح له نافذة الاشتراك،
وعند دخوله تُنقل مفضلة متصفحه إلى حسابه. تُعرَّف الرسالة بدينها وعنوانها حتى لا يضرها تغيير ترتيب الرسائل؛
وإن تغيّر عنوانها تُفتح برقمها وقت الحفظ.

## الحسابات والإحصاءات (Supabase)

أزرار «الدخول / الاشتراك» مخفية ولا يُسجَّل أي استخدام ما دام `js/config.js` فارغًا. لتفعيلها:

1. أنشئ مشروعًا في [supabase.com](https://supabase.com) واختر منطقة الخادم بما يوافق نظام حماية البيانات الشخصية.
2. **SQL Editor**: الصق محتوى `supabase/schema.sql` كاملًا وشغّله (إعادة تشغيله لاحقًا آمنة).
3. انسخ **Project URL** و**Publishable key** (أو `anon` في المشاريع القديمة) إلى `js/config.js`.
   لا تضع المفتاح السري (`secret` / `service_role`) في الموقع أبدًا.
4. **Authentication ← URL Configuration**:
   - Site URL: رابط الموقع المنشور.
   - Redirect URLs: رابط الموقع المنشور و`http://localhost:8080/`.
5. **Authentication ← Emails ← SMTP Settings**: اربط خدمة بريد (مثل بريد الجمعية أو Resend).
   مُرسل Supabase المدمج لا يرسل إلا لأعضاء فريق المشروع وبعدد محدود، فلا يصلح للزوار.
6. اختياري: عرّب قوالب رسائل التأكيد واستعادة كلمة المرور من **Authentication ← Emails**،
   واجعل الحد الأدنى لطول كلمة المرور 8 ليطابق الموقع.
7. **الدخول بحساب Google**:
   - في [Google Cloud Console](https://console.cloud.google.com) ← **Google Auth Platform**: جمهور External، وفي Branding
     رابط الموقع ورابط `privacy.html`، والنطاقان المعتمدان `byenah.com` و`<المشروع>.supabase.co`، ثم **Publish app**.
   - **Clients ← Create client** (Web application): الأصل `https://rasael.byenah.com`، ورابط العودة
     `https://<المشروع>.supabase.co/auth/v1/callback`.
   - في Supabase ← **Authentication ← Sign In / Providers ← Google**: فعّله والصق Client ID وClient secret.
   - انسخ Client ID إلى `GOOGLE_CLIENT_ID` في `js/config.js` (عام بطبيعته). يُعرض به زر Google الرسمي في نافذة الدخول،
     فتقول جوجل «المتابعة إلى byenah.com» بدل عنوان Supabase. إن تعذّر تحميل أداة جوجل يظهر زر احتياطي يحوّل عبر Supabase.
   - الدولة لا تُطلب من المشترك: تُعرف من اتصاله بعد الدخول (`claim_country` في `schema.sql`)، بالبريد أو بجوجل.

### المشرفون

اشترك من الموقع وأكّد بريدك، ثم شغّل في **SQL Editor** (مع بريدك):

```sql
update public.profiles set is_admin = true
where id = (select id from auth.users where email = 'name@example.com');
```

بعدها يظهر للمشرف زر «الإحصاءات والمشتركون» في نافذة «حسابي»، أو افتح `admin.html` مباشرة.
الصلاحية محمية في قاعدة البيانات نفسها: غير المشرف لا يستطيع قراءة السجل أو قائمة المشتركين أو الملاحظات ولو فتح الصفحة.

### الملاحظات

ما يُرسَل من نموذج «إرسال ملاحظة» يُحفظ في جدول `feedback`، ويظهر للمشرف في قسم «الملاحظات»
بصفحة الإحصاءات (بحث، تصدير CSV، وحذف). الزائر يستطيع الإضافة فقط ولا يقرأ شيئًا.
عند تعديل `supabase/schema.sql` أعد تشغيله كاملًا في **SQL Editor**.

### ما الذي يُحفظ

- **المشتركون**: الاسم والبريد (كلمة المرور مشفّرة لدى Supabase)، والدولة من اتصالهم بالإنترنت عبر Cloudflare
  (ترويسة `cf-ipcountry`) دون حفظ عنوان الاتصال. من يستخدم VPN تُسجَّل له دولة الخادم.
- **المفضلة**: الرسائل التي يحفظها كل مشترك، ولا يراها غيره.
- **سجل الاستخدام** (لكل الزوار): فتح الموقع، بدء الرسائل (الدين والحجم واللغة)، الرسائل المقروءة،
  النسخ والمشاركة والتحميل، إرسال ملاحظة، ونوع الجهاز. الزائر يُعرَّف برقم عشوائي في متصفحه،
  ويُربط نشاطه بحسابه إن كان مسجّلًا.
